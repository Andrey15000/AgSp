# АгроСфера — рабочее пространство, версия 7

Демонстрационный сайт Андрея Кирсаненко. Оформление соответствует первой концепции «АгроСфера»: тёмно-синяя палитра, ярко-зелёные акценты, поиск в верхней панели, большая карта слева, показатели справа, график, станции и погода ниже.

## Запуск

В папке `dist` находятся все файлы сайта. Запустите из неё:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. В Windows вместо `python` можно использовать `py`. Не открывайте `index.html` двойным щелчком: модули JavaScript требуют HTTP-сервера. Устанавливать npm-пакеты не нужно.

## GitHub Pages

Загрузите **содержимое папки dist** в корень репозитория: `index.html`, CSS, JS, `field.jpg` и папку `vendor` целиком. В Settings → Pages выберите Deploy from a branch, ветку main, папку /(root). Файлы должны сохранить взаимное расположение. Библиотека Three.js включена локально, её лицензия лежит в `vendor/LICENSE.txt`.

При скачивании отдельного архива `AgroSfera_concept1_v7.zip` файлы сайта уже находятся в корне: загрузите всё содержимое архива.

## Возможности

- Обзор: интерактивная карта 48 участков и 12 виртуальных станций, выбор с мыши и клавиатуры, 12 показателей, 3 погодных сценария, лабораторный состав почвы.
- Участки: поиск по номеру и станции, фильтр состояния и станции, сортировка по приоритету или влажности, переход к измерениям и создание задачи.
- Данные: история 8–15 октября 2026, UTC, шаг 15 минут. Фильтры периода, участка, станции, типа и параметров; страницы таблицы; CSV и JSON по выбранным фильтрам; полный архив; отдельный CSV лабораторных проб.
- Аналитика: суточный ритм, микроклимат, корреляции и диаграмма рассеяния; данные выбранного участка или средние с весами по площади.
- Станция: 3D-модель, разборка, вращение, подписи и схема. При недоступном WebGL автоматически включается интерактивная двумерная схема с описаниями узлов.
- Задачи: создание, изменение, завершение, удаление с подтверждением, сроки, приоритеты, заметки, связь с участком, JSON-экспорт.
- Настройки: название поля, культура, пороги влажности и температуры, резервная копия и восстановление JSON с проверкой формата.
- Светлая/тёмная тема, мобильная компоновка, доступность с клавиатуры.

## Сохранение

Задачи и настройки хранятся в localStorage конкретного браузера и адреса сайта. При очистке браузера или переходе на другой домен они не переносятся автоматически. Используйте Настройки → Скачать резервную копию, затем Восстановить из JSON. Импорт заменяет задачи и настройки после подтверждения. Максимум 1000 задач; файл резервной копии до 3 МБ.

Выбранный сценарий, участок, слой карты и фильтры журнала также сохраняются. Реальных персональных данных и предзаполненных задач в исходниках нет.

Это полностью работающий клиентский демонстратор. Телеметрия синтетическая, дата среза фиксирована: 15.10.2026 12:00 UTC. Лабораторные пробы — отдельный демонстрационный срез 08.10.2026. Карта имеет условную геометрию, без геопривязки. Фото: Andreas Gücklhorn / Unsplash; атрибуция есть на сайте.

Подключения к датчикам, общей серверной БД, многопользовательской синхронизации и обученной модели ИИ нет. Сценарии и пороговые рекомендации вычисляются локально. Пороги не являются универсальной агрономической нормой. Для реального внедрения нужны API оборудования, серверное хранение, калибровка и проверка специалистом.

## Файлы

`dist/app.js` — расчёт данных, карта, аналитика, журнал, задачи и настройки.
`dist/dashboard.css` — базовая компоновка рабочего пространства.
`dist/concept-one.css` — оформление по первой концепции и мобильные стили.
`dist/style.css`, `dist/premium.css` — существующие компоненты сайта.
`dist/station.js` — 3D и резервная схема.
`dist/enhance.js` — тема и прозрачность карты.
`dist/vendor/three.js` — локальная зависимость.

Прежние скрипты сборки в корне репозитория сохранены для истории. Для текущей версии источником публикации является папка `dist`; не запускайте старые `upgrade*.mjs`, иначе они могут перезаписать текущие файлы.
